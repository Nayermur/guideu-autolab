সেটআপ

আপনার পেজ, বিষয় আর কী-গুলো দিন। প্রতিটার পাশে “কীভাবে নেবো?” চাপলে ধাপে ধাপে দেখাবে, আর “পরীক্ষা করুন” চাপলে সাথে সাথে বোঝা যাবে ঠিক আছে কিনা।

১. আপনার পেজ

২. কোন বিষয়ে পোস্ট হবে

টিম এই বিষয়গুলো পালা করে খুঁজবে আর পোস্ট বানাবে।

৩. Gemini API Key

টিমের লেখা আর আপনার সহকারী পাখি এই কী দিয়ে চলে। ফ্রি প্ল্যানেই হবে।

কীভাবে নেবো?
  1. aistudio.google.com/apikey খুলুন, আপনার Google অ্যাকাউন্ট দিয়ে লগইন করুন।
  2. Create API key চাপুন (প্রজেক্ট চাইলে নতুন একটা বানিয়ে নিন)।
  3. যে কী দেখাবে সেটা কপি করে ওপরের ঘরে বসান।

৪. Instagram

আপনি approve করলে পোস্ট এই অ্যাকাউন্টে নিজে থেকে চলে যাবে।

কীভাবে নেবো?
  1. আপনার Instagram অ্যাকাউন্ট Professional (Business বা Creator) হতে হবে, আর একটা Facebook পেজের সাথে যুক্ত থাকতে হবে।
  2. business.facebook.com-এ একটা Business portfolio খুলুন (না থাকলে বানান), সেখানে Facebook পেজ আর Instagram অ্যাকাউন্ট যোগ করুন।
  3. developers.facebook.com/apps → Create App → টাইপ Business → আপনার portfolio বেছে নিন।
  4. অ্যাপে Instagram প্রোডাক্ট যোগ করুন → API setup with Facebook login।
  5. business.facebook.com → Settings → Users → System users → Add (Admin)। তারপর Assign assets: অ্যাপ, Facebook পেজ আর Instagram অ্যাকাউন্ট (Full control)।
  6. সেই System user → Generate new token → আপনার অ্যাপ → Expiration: Never → permission: instagram_basic, instagram_content_publish, pages_show_list, pages_read_engagement, business_management → Generate → টোকেন কপি করে ওপরে বসান।
  7. এরপর খুঁজে দাও চাপুন, আপনার Instagram অ্যাকাউন্টটা বেছে নিন। IG User ID নিজে থেকে বসে যাবে।

আটকে গেলে আমাদের জানান, আমরা সাথে থেকে করে দেব।

৫. Telegram

প্রতিটা নতুন পোস্টের ড্রাফট Approve / Reject বাটনসহ আপনার Telegram-এ আসবে।

কীভাবে নেবো?
  1. Telegram-এ @BotFather খুলুন, /newbot লিখে পাঠান।
  2. বটের একটা নাম দিন, তারপর একটা username (শেষে অবশ্যই bot থাকবে, যেমন mypage_post_bot)।
  3. BotFather একটা টোকেন দেবে (দেখতে 123456789:AAH...)। পুরোটা কপি করে ওপরের ঘরে বসান।
  4. BotFather যে লিংক দিয়েছে সেটা দিয়ে আপনার নতুন বটটা খুলুন, Start চাপুন, একটা মেসেজ (যেমন hi) পাঠান।
  5. এখানে ফিরে খুঁজে দাও চাপুন, আপনার নামটা বেছে নিন। Chat ID নিজে থেকে বসে যাবে।
  6. পরীক্ষা করুন চাপলে বট আপনাকে একটা মেসেজ পাঠাবে।
